# Discourse Corpus Study

This repository is for a non-commercial academic research project on English online interactive discourse.

## Project purpose

The project studies how emotion, reason, stance, and modality are constructed in public online discussions.

## Data scope

The project will collect only public posts and public comments from selected public online communities through the official API.

The following fields may be collected:

- public post title
- public post text
- public comment body
- post ID
- comment ID
- parent ID
- timestamp
- score
- subreddit/community name
- thread structure

## Excluded data

This project will not collect:

- private messages
- chat data
- emails
- user profile data
- sensitive personal information

## Data handling

User identifiers will be removed or anonymized before analysis. Raw platform data will not be redistributed. Published examples will be anonymized and used only for academic purposes.

## App behavior

The script is read-only. It will not post, comment, vote, send messages, moderate communities, or automate user interactions.

## Research use

This project is for thesis / academic research only and has no commercial purpose.
